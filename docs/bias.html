Only the overall rating is shown. A type whose offence and defence are wrong in opposite directions is a disagreement about which end the value comes from, and both sources can be right about how good the player is; only the total says a rating is wrong. Our overall is stretched once, globally, by x1.101 to match the consensus's spread, so that a type of stars does not read as biased merely because the two scales differ; the unstretched figure is in the last column.
